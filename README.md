# 🏮 The Last Lantern

**The Last Lantern** is a short 3D atmospheric horror and exploration game made with **Godot** for a 5-day game jam.

You enter a mysterious forest where people have disappeared without a trace. The only way forward is to find and light four forgotten lanterns scattered throughout the forest.

But every lantern reveals more than just the path...

As the forest slowly comes to life, you will discover an abandoned shrine, uncover mysterious symbols, and enter an ancient temple where the truth behind the lanterns awaits.

### 🎮 Features

- 🌲 Atmospheric 3D forest exploration
- 🏮 Lantern-based progression
- ⛩️ Ancient shrine and temple environments
- 🧩 Simple environmental puzzles
- 👻 Psychological horror without complex combat
- 🎧 Atmospheric sound and environmental effects
- 🎬 Short story-driven ending

### 🛠️ Built With

- Godot 4
- GitHub / GitHub Desktop
- Blender / 3D assets as needed

### 🎯 Game Jam Goal

The project is designed to be completed within **5 days**, focusing on atmosphere, level design, exploration, and a polished short gameplay experience rather than complex combat or large open-world systems.
